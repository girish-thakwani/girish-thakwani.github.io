## Overview

PingPilot is a multimodal web agent built to automate complex tasks in a browser using LLMs and Playwright.

## Highlights

- Built an agent that can perform complex web tasks, such as filling forms and navigating pages, using a combination of LLMs and Playwright.
- Implemented a feedback loop where the agent learns from its mistakes and improves its performance over time.
- Achieved an 85% task success rate on a benchmark set of web tasks, outperforming existing solutions by 20%.
